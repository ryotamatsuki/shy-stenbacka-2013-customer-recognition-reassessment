## Stage-14 conservative rule

Where a current public journal-specific guide is inaccessible, the submission package follows the stricter combination of:
1. current IEP scope/portal;
2. current Elsevier-wide policies;
3. legacy official IEP author-pack requirements that do not conflict with current policy;
4. current 2026 secondary journal-template corroboration.

No unresolved item above changes scientific content. Authenticated-portal-only identity/contact/reviewer fields are not fabricated in the repository.
